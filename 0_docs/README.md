# Supplementary documentation

Working notes and derived tables that accompany the paper. Format names follow
the paper: **LOG8-SUM** (`mxlog8`), **LOG8-MAX** (`mxlog8_logdom`).

- `EXPERIMENT_SUMMARY.md` — end-to-end campaign summary and platform notes.
- `FORMAT_ACCURACY.md` — per-format inference-output sanity check.
- `dvfs_results_tables.md` — expanded voltage-underscaling result tables.

Where any number here differs from the published paper (e.g. intermediate WNS or
accuracy runs), the paper and `6_analysis/reproduce.py` are authoritative.
